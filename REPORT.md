# Звіт про виконання завдання

## Тема

Додаток "Моє місто та Про мене" на React Native (Expo).

## Що зроблено

1. Створено додаток на Expo Router з TypeScript.
2. Реалізовано 3 сторінки:
   - **Головна** (`app/index.tsx`) — з двома кнопками навігації.
   - **Моє місто** (`app/city.tsx`) — список визначних місць через `FlatList`.
   - **Про мене** (`app/about.tsx`) — інформація про мене, аватар, навички.
3. Навігація через компонент `Link` з `expo-router`.
4. Використано `FlatList` для списку місць та `.map()` для списку навичок.
5. Стилізація через `StyleSheet.create()`, єдина кольорова схема:
   - Основний: `#1a1a2e` (темно-синій)
   - Фон: `#f5f5f5` (світло-сірий)
   - Акцент: `#16213e` (насичений синій)
6. Картки з тінями (`shadowColor`, `shadowOffset`, `elevation`).
7. Іконки — через emoji (🌳🎭🌊🏛️💻📱🎸📚✈️👤).

## Труднощі

- Налаштування Expo та вирішення проблем з підключенням (використовував web-версію).

## Що вивчено

- Основи Expo Router та файлової навігації.
- Робота з `FlatList`, `ScrollView`, `View`, `Text`, `Link`.
- Стилізація через `StyleSheet.create()`.
- Навігація через `Link` та `Stack`.
